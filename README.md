# أستوديو النغم — تطبيق إدارة طلاب الموسيقى

## خطوات نشر التطبيق على الإنترنت (بدون أي خبرة برمجية)

### 1. ارفع هذا المجلد على GitHub
- اعمل حساب مجاني على github.com (لو ما عندك أصلاً)
- من الصفحة الرئيسية دوس "New repository"
- اسم المستودع: مثلاً `music-teacher-app`
- بعد ما ينعمل، دوس "uploading an existing file"
- اسحب وأفلت كل ملفات هذا المجلد (بما فيها مجلد src كامل)
- دوس "Commit changes"

### 2. اربطه بـ Vercel
- روح لـ vercel.com واعمل حساب (اختار "Continue with GitHub")
- دوس "Add New Project"
- اختار المستودع يلي رفعته (`music-teacher-app`)
- Vercel رح يتعرف تلقائياً إنه مشروع Vite — بس دوس "Deploy"
- بعد دقيقة أو دقيقتين، رح تاخد رابط حقيقي شغال (مثلاً music-teacher-app.vercel.app)

### 3. أي تحديث بالمستقبل
أي تعديل ترفعه على GitHub، Vercel بينشره تلقائياً بعد ثواني — ما بتحتاج تعيد كل الخطوات.

## ملاحظة مهمة عن حفظ البيانات
البيانات هلق بتتحفظ بمتصفح كل جهاز لحاله (localStorage) — يعني لو المعلم فتح التطبيق من موبايله وبعدين من كمبيوتره، البيانات ما بتكون نفسها بين الجهازين. هاد كافي للتجربة الأولى مع معلم حقيقي، وبعدين نضيف قاعدة بيانات حقيقية (متل Supabase) تخلي البيانات موحدة على كل الأجهزة.
